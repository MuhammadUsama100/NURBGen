# NURBGen: High-Fidelity Text-to-CAD Generation through LLM-Driven NURBS Modeling

## Objective
NURBGen is the first framework that generates high-fidelity, editable 3D CAD models directly from natural-language text using NURBS-based symbolic representations, enabling direct conversion to B-Rep CAD geometry.
